# 工程项目管理监控看板 — 功能测试用例

> **模块路径：** 智慧工地 / 项目管理 → 项目监控看板（单项目详情页）  
> **页面功能：** 项目基本信息、关键节点、劳务出勤、物资进场、安全质量、设备运行、环境监测等数据展示与查看  
> **版本：** v1.0  
> **编写日期：** 2026-05-18

---

## 一、用例字段说明

| 字段 | 说明 |
|------|------|
| ID | 用例唯一编号 |
| 功能点 | 被测功能模块 |
| 测试场景 | 具体测试场景描述 |
| 前置条件 | 执行前需满足的条件 |
| 测试数据 | 执行用例所需输入数据（占位值，执行时从测试环境获取） |
| 操作步骤 | 按序号编写的详细操作步骤 |
| 预期结果 | 期望的系统行为 |
| 优先级 | P0 / P1 / P2 |
| 用例类型 | 功能测试 / 界面测试 / 边界测试 / 异常测试 / 权限测试 |
| 覆盖点 | 需求或功能覆盖标识 |

**测试数据约定：** 项目名称、人员姓名、物资名称等均使用占位描述，执行时从测试数据清单获取，不写死具体业务名称。

---

## 二、测试范围

| 模块 | 说明 |
|------|------|
| 页面框架 | 页头、面包屑、左侧菜单、用户区、导出等 |
| 项目基本信息 | 节点、负责人、计划/实际时间、状态 |
| 关键节点进度 | 进度条、完成百分比、查看详情 |
| 劳务人员动态 | 班组出勤统计、出勤率 |
| 人员出勤详情 | 个人打卡/刷卡记录 |
| 物资进场明细 | 计划与实际进场、偏差 |
| 安全隐患排查 | 隐患、整改、状态色标 |
| 质量检查记录 | 检查部位、结果、备注 |
| 关键设备运行 | 运行状态、累计运行时间 |
| 环境监测数据 | PM2.5、噪声、温湿度等实时数据 |
