## 一、用例字段说明

|------|------|

## 二、项目详情业务规则速查（需求 V1.6）

| 规则编号 | 检查项 | 预警/判别规则 | 需求章节 |
|----------|--------|---------------|----------|
| R-01 | 未开标访问限制 | 项目经理、招标人、代理机构：未开标项目**无权**查看平台检测信息 | §2.3 |
| R-02 | 评审专家时效 | 开标前、项目结束后**不可**查看投标人文件检测信息 | §2.3 |
| R-03 | 招标信息质疑 | 针对招标条件的异议/投诉 **合计 ≥3 次** 预警 | §3.2.4 |
| R-04 | 招标文件质疑 | 不合理限制条件异议/投诉 **合计 ≥3 次** 预警 | §3.2.5 |
| R-05 | 投标投诉质疑 | 反映投标人弄虚作假异议/投诉 **合计 ≥2 次** 预警 | §3.3.12 |
| R-06 | 中标投诉质疑 | 针对中标候选人异议/投诉 **合计 ≥3 次** 预警 | §3.4.1 |
| R-07 | 投标次数预警 | 一年内投标 **≥20 次** 且**从未中标** | §3.3.5 |
| R-08 | 相同投标预警 | 近 **365 天**内共同投标 **≥15 次** 且合计中标 **≥5 次** | §3.3.6 / §4.3.2.4 |
| R-09 | 投标时间相近 | 非临近截止时间时段，**1 小时内 ≥10 份** 投标文件集中上传 | §3.3.9 / §4.3.2.11 |
| R-10 | 报价规律校验 | 投标人 **>3 家**，报价呈等差规律，偏差 **≤10%** 高亮 | §4.3.2.10 |
| R-11 | 投标笔迹 | 相同笔迹数量 **>0** 标注异常高亮 | §4.3.2.8 |
| R-12 | 保证金/环境/IP/属性 | 多投标单位共用账户、MAC、IP 或文件属性时异常高亮 | §4.3.2.5～9 |
