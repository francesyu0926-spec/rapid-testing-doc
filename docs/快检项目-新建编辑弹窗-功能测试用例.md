# 招投标检测平台 — 快检项目「新建/编辑」弹窗功能测试用例

> **模块路径：** 数据展示应用 → 快检项目 → 新建项目 / 编辑  
> **页面功能：** 项目信息录入、招标文件/备案文件/投标文件上传、投标单位动态增删  
> **版本：** v1.1  
> **编写日期：** 2026-05-18  
> **关联文档：** [快检项目-功能测试用例.md](快检项目-功能测试用例.md)（列表页）

## 一、用例字段说明

| 字段 | 说明 |
|------|------|
| ID | 用例唯一编号 |

## 五、新建 vs 编辑 对照检查项

| 检查项 | 新建项目 | 编辑 |
|--------|----------|------|
| 弹窗标题 | 新建项目 | 编辑 |
| 主按钮 | 创建 | 保存 |
| 项目名称 | 空 | 回显 |
| 招标文件 | 必传 | 回显，可删换 |
| 备案文件 | 可选 | 回显或空 |
| 投标单位 | 默认 1 组空行 | 回显多组 |
| 提交后列表 | 新增 1 条 | 更新对应行 |
