# 招投标检测平台 — 快检项目「新建/编辑」功能测试用例

> **模块路径：** 数据展示应用 → 快检项目 → 新建项目 / 编辑  
> **页面功能：** 项目信息录入、招标文件/备案文件/投标文件上传、投标单位动态增删  
> **版本：** v1.3  
> **编写日期：** 2026-05-18  
> **关联文档：** [快检项目-功能测试用例.md](快检项目-功能测试用例.md)（列表页）

> **交互说明：** 新建项目从列表页右侧滑出**抽屉**；编辑仍为**弹窗**。

---

## 一、用例字段说明

| 字段 | 说明 |
|------|------|
| ID | 用例唯一编号 |
| 功能点 | 被测功能模块 |
| 测试场景 | 具体测试场景描述 |
| 前置条件 | 执行前需满足的条件 |
| 测试数据 | 执行用例所需输入数据（占位值，执行时从测试环境获取） |
| 操作步骤 | 按序号编写的详细操作步骤，每步对应一个明确动作 |
| 预期结果 | 期望的系统行为 |
| 优先级 | P0 / P1 / P2 |
| 用例类型 | 功能测试 / 界面测试 / 边界测试 / 异常测试 / 权限测试 / 安全测试 |
| 覆盖点 | 需求或功能覆盖标识 |

**操作步骤编写约定：** 步骤需包含具体控件名称、输入/上传内容及点击动作。

---

## 二、表单字段说明

| 序号 | 字段 | 是否必填 | 约束 |
|------|------|----------|------|
| 1 | 项目名称 | 是（*） | 文本输入 |
| 2 | 添加招标文件 | 是（*） | 仅支持 PDF |
| 3 | 添加备案文件 | 否 | 仅支持 PDF |
| 4 | 添加投标文件 | 是（*） | 至少一组；每组：投标单位 + PDF |

| 场景 | 标题 | 主按钮 | 容器 |
|------|------|--------|------|
| 新建 | 新建项目 | 创建 | 抽屉 |
| 编辑 | 编辑 | 保存 | 弹窗 |

## 五、新建 vs 编辑 对照检查项

| 检查项 | 新建项目 | 编辑 |
|--------|----------|------|
| 容器 | 抽屉 | 弹窗 |
| 标题 | 新建项目 | 编辑 |
| 主按钮 | 创建 | 保存 |
| 项目名称 | 空 | 回显 |
| 招标文件 | 必传 | 回显，可删换 |
| 备案文件 | 可选 | 回显或空 |
| 投标单位 | 默认 1 组空行 | 回显多组 |
| 提交后列表 | 新增 1 条 | 更新对应行 |
