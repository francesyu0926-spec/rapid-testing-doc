# 招投标检测平台 — 快检项目「新建/编辑」弹窗功能测试用例

> **模块路径：** 数据展示应用 → 快检项目 → 新建项目 / 编辑  
> **页面功能：** 项目信息录入、招标文件/备案文件/投标文件上传、投标单位动态增删  
> **版本：** v1.0  
> **编写日期：** 2026-05-18  
> **关联文档：** [快检项目-功能测试用例.md](快检项目-功能测试用例.md)（列表页）

---

## 一、测试范围

| 模块 | 说明 |
|------|------|
| 弹窗展示 | 新建/编辑弹窗标题、字段、必填标识、说明文案 |
| 项目名称 | 必填、输入校验、编辑回显 |
| 招标文件 | 必填、PDF 格式、上传/删除/替换 |
| 备案文件 | 非必传、PDF 格式、上传/删除 |
| 投标文件 | 投标单位名称 + 文件成组、至少一组、多组增删 |
| 弹窗操作 | 取消、保存（编辑）、创建（新建）、关闭 |
| 业务联动 | 与列表页数据一致性 |

---

## 二、表单字段说明

| 序号 | 字段 | 是否必填 | 约束 |
|------|------|----------|------|
| 1 | 项目名称 | 是（*） | 文本输入 |
| 2 | 添加招标文件 | 是（*） | 仅支持 PDF；上传按钮 |
| 3 | 添加备案文件 | 否（非必传） | 仅支持 PDF；上传按钮 |
| 4 | 添加投标文件 | 是（*） | 至少一组，可添加多组；每组含「投标单位」+ 投标文件上传；提示「请输入单位名称并上传投标文件」 |

**弹窗差异：**

| 场景 | 标题 | 主按钮 |
|------|------|--------|
| 新建 | 新建项目 | 创建 |
| 编辑 | 编辑 | 保存 |

## 五、新建 vs 编辑 对照检查项

| 检查项 | 新建项目 | 编辑 |
|--------|----------|------|
| 弹窗标题 | 新建项目 | 编辑 |
| 主按钮文案 | 创建 | 保存 |
| 项目名称 | 空 | 回显 |
| 招标文件 | 必传，无默认文件 | 回显，可删换 |
| 备案文件 | 可选 | 回显或空 |
| 投标单位 | 默认 1 组空行 | 回显多组，可增删 |
| 提交后列表 | 新增 1 条 | 更新对应行 |

## 六、优先级说明

| 级别 | 说明 |
|------|------|
| P0 | 必填校验、PDF 限制、单/多组投标、创建/保存、取消、回显 |
| P1 | 边界长度、重复提交、权限、失败提示、未保存确认 |
| P2 | 遮罩关闭、损坏文件、断网等次要场景 |
