# 招投标检测平台 — 快检项目功能测试用例

> **模块路径：** 数据展示应用 → 快检项目  
> **页面功能：** 快检项目列表查询、新建/刷新、编辑、校验任务执行  
> **版本：** v1.4  
> **编写日期：** 2026-05-18

> **不在测试范围：** 页头应用 Tab 切换（「AI审计应用」「数据展示应用」「智慧审计大屏」），本页用例不涉及该区域。  
> **暂不测试：** 筛选区「开标时间」字段及列表「开标时间」列（当前版本未上线）。

---

## 一、用例字段说明

| 字段 | 说明 |
|------|------|
| ID | 用例唯一编号 |
| 功能点 | 被测功能模块 |
| 测试场景 | 具体测试场景描述 |
| 前置条件 | 执行前需满足的条件 |
| 测试数据 | 执行用例所需输入数据（占位值，执行时从测试环境获取） |
| 操作步骤 | 按序号编写的详细操作步骤，每步对应一个明确动作 |
| 预期结果 | 期望的系统行为 |
| 优先级 | P0 / P1 / P2 |
| 用例类型 | 功能测试 / 界面测试 / 边界测试 / 异常测试 / 权限测试 / 安全测试 |
| 覆盖点 | 需求或功能覆盖标识 |

**操作步骤编写约定：** 步骤需包含具体页面位置、控件名称、输入内容及点击动作，便于测试人员逐步执行。

**测试数据约定：** 项目名称、招标方等均使用占位描述，执行时从测试数据清单获取。

## 五、关键业务规则

```
校验任务状态「剩余:Y」与操作按钮：
  Y > 0  →  显示「立即执行」
  Y = 0  →  显示「重新执行」
  任意行 →  均显示「编辑」
```

**对照验证：** 使用剩余>0 与剩余=0 的行分别验证 KJ-504～KJ-507。
