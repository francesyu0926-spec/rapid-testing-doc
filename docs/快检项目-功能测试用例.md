## 四、关键业务规则

```
校验任务状态「剩余:Y」与操作按钮：
  Y > 0  →  显示「立即执行」
  Y = 0  →  显示「重新执行」
  任意行 →  均显示「编辑」
```

**对照验证建议：** 使用列表中「剩余>0」与「剩余=0」的行分别验证 KJ-504～KJ-507。

## 五、优先级说明

| P0 | 核心流程：列表、查询、新建、编辑、执行/重跑、退出 |

| P2 | 体验与次要功能：折叠栏、长文本、标段展示 |
