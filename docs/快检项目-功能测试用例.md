> **版本：** v1.1  
> **编写日期：** 2026-05-18

## 一、用例字段说明

## 五、关键业务规则

```
校验任务状态「剩余:Y」与操作按钮：
  Y > 0  →  显示「立即执行」
  Y = 0  →  显示「重新执行」
  任意行 →  均显示「编辑」
```

**对照验证：** 使用剩余>0 与剩余=0 的行分别验证 KJ-504～KJ-507。
